# Changelog

All notable changes to this project are documented here.

## [1.0.0] - 2026-11-18

### Added
- User registration and login with JWT authentication.
- Task CRUD operations.
- PostgreSQL database integration.
- React and TypeScript frontend.
- Responsive application UI.
- Backend unit tests using Vitest.
- Docker Compose setup for frontend, backend, and PostgreSQL.
- GitHub Actions CI workflow.
- Nginx configuration for serving the frontend.
- Project documentation and application screenshots.

### Tested
- Backend service unit tests.
- Frontend linting and production build.
- Dockerized application startup.
- API and database integration.
