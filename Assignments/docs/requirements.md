# Requirements

## User Stories

1. As a user, I want to add tasks to manage my activities.
2. As a user, I want to view all tasks.
3. As a user, I want to edit existing tasks.
4. As a user, I want to delete tasks.
5. As a user, I want to mark tasks as completed.
6. As a user, I want to filter tasks by status.
7. As a user, I want to search tasks.
8. As a user, I want to save tasks for future access.

## Acceptance Criteria
- Users can add, view, edit and delete tasks.
- Users can mark tasks as completed.
- Users can search and filter tasks.
- Tasks should be saved properly.
